🚀 JKB Website Deployment

Schritt-für-Schritt Anleitung für GitHub + Netlify

✅ Status: Repository bereit!

Ihr Code ist lokal committed und bereit für das Deployment. Alle Formulare sind konfiguriert!

1

📁 GitHub Repository erstellen

  1. Gehen Sie zu github.com
  2. Klicken Sie auf das + Symbol oben rechts
  3. Wählen Sie "New repository"
  4. Repository Name: JKB-Website
  5. Setzen Sie es auf "Public"
  6. NICHT "Initialize with README" ankreuzen (ist schon lokal)
  7. Klicken Sie "Create repository"
2

📤 Code zu GitHub pushen

Führen Sie diese Befehle im Terminal aus (im JKB-Website Ordner):

# Repository URL setzen (ersetzen Sie USERNAME mit Ihrem GitHub Namen) git remote add origin https://github.com/USERNAME/JKB-Website.git # Branch umbenennen auf main git branch -M main # Code hochladen git push -u origin main
💡 Tipp: Die exakte URL finden Sie auf der GitHub Repository-Seite unter "Quick setup"
3

🌐 Netlify Deployment

  1. Gehen Sie zu netlify.com
  2. Registrieren Sie sich (falls noch nicht geschehen)
  3. Klicken Sie "New site from Git"
  4. Wählen Sie "GitHub"
  5. Autorisieren Sie Netlify (falls nötig)
  6. Wählen Sie das "JKB-Website" Repository
  7. Deploy Settings:
    Branch to deploy: main Build command: (leer lassen) Publish directory: . (nur ein Punkt)
  8. Klicken Sie "Deploy site"
4

📧 Kontaktformular aktivieren

Nach dem Deployment (ca. 2-3 Minuten):

  1. Gehen Sie zu Ihrem Netlify Dashboard
  2. Klicken Sie auf Ihre neue Website
  3. Gehen Sie zu "Forms" im Seitenmenü
  4. Sie sollten das "contact" Formular sehen
  5. Klicken Sie darauf → "Settings & usage"
  6. Scrollen Sie zu "Form notifications"
  7. Klicken Sie "Add notification"
  8. Wählen Sie "Email notification"
  9. Email to notify: office@fj-marketing.com
  10. Klicken Sie "Save"
⚠️ Wichtig: Falls das "contact" Formular NICHT erscheint, triggern Sie ein neues Deployment unter "Deploys" → "Trigger deploy"
5

🧪 Testen

  1. Öffnen Sie Ihre neue Netlify-URL (z.B. amazing-site-123456.netlify.app)
  2. Scrollen Sie zum Kontaktformular
  3. Füllen Sie es mit echten Daten aus
  4. Senden Sie es ab
  5. Sie sollten zur Success-Seite weitergeleitet werden
  6. Prüfen Sie Netlify Dashboard → Forms für die Submission
  7. Prüfen Sie office@fj-marketing.com für die E-Mail (auch Spam!)
6

🎯 Custom Domain (Optional)

Wenn Sie eine eigene Domain haben:

  1. Netlify Dashboard → "Domain settings"
  2. Klicken Sie "Add custom domain"
  3. Geben Sie Ihre Domain ein (z.B. jkb-software.de)
  4. Folgen Sie den DNS-Anweisungen
  5. SSL wird automatisch eingerichtet

🎉 Fertig!

Ihre Website ist jetzt live mit funktionierendem Kontaktformular!
