🔧 Kontaktformular Debugging

Schritt-für-Schritt Lösung wenn E-Mails nicht ankommen

❌ Problem: Keine E-Mails erhalten

Das ist ein häufiges Problem. Hier ist die systematische Lösung:

🔍 Schritt 1: Netlify Dashboard prüfen

  1. Gehen Sie zu Ihrem Netlify Dashboard
  2. Klicken Sie auf Ihre JKB-Website
  3. Gehen Sie zu "Forms" im Seitenmenü
  4. Schauen Sie, ob das "contact" Formular dort erscheint
🚨 Häufigster Fehler:
Wenn das Formular NICHT in der Liste erscheint, hat Netlify es nicht erkannt!

🔧 Schritt 2: Formular-Erkennung erzwingen

Netlify erkennt Formulare nur bei Deployment. Hier ist der Fix:

Option A: Re-Deploy erzwingen

  1. Gehen Sie zu Ihrem Netlify Dashboard
  2. Klicken Sie auf "Deploys"
  3. Klicken Sie "Trigger deploy" → "Deploy site"
  4. Warten Sie bis Deployment fertig ist
  5. Prüfen Sie wieder unter "Forms"

Option B: HTML Pre-Render (Empfohlen)

Erstellen Sie eine statische Version des Formulars:

<!-- Fügen Sie das am Ende von index.html hinzu (vor </body>) --> <form name="contact" netlify netlify-honeypot="bot-field" hidden> <input type="text" name="name" /> <input type="email" name="email" /> <input type="text" name="subject" /> <textarea name="message"></textarea> </form>

📧 Schritt 3: E-Mail Konfiguration

  1. Gehen Sie zu "Forms" in Netlify
  2. Klicken Sie auf "contact"
  3. Gehen Sie zu "Settings & usage"
  4. Scrollen Sie zu "Form notifications"
  5. Klicken Sie "Add notification" → "Email notification"
  6. Geben Sie ein: office@fj-marketing.com
  7. Speichern Sie

🧪 Schritt 4: Test-Submission

  1. Gehen Sie zu Ihrer Website
  2. Füllen Sie das Kontaktformular aus
  3. Senden Sie es ab
  4. Gehen Sie SOFORT zu Netlify Dashboard → Forms
  5. Schauen Sie, ob die Submission dort erscheint
✅ Wenn Submission sichtbar ist:
Das Formular funktioniert! E-Mail kommt in 1-5 Minuten.
❌ Wenn keine Submission sichtbar:
Das Formular wird nicht richtig übermittelt → Siehe Schritt 5

🛠️ Schritt 5: HTML Fix (Falls Submissions fehlen)

Das Problem liegt meist im HTML. Hier ist der garantiert funktionierende Code:

<form name="contact" method="POST" data-netlify="true"> <input type="hidden" name="form-name" value="contact" /> <div> <input type="text" name="name" placeholder="Ihr Name" required /> </div> <div> <input type="email" name="email" placeholder="Ihre E-Mail" required /> </div> <div> <input type="text" name="subject" placeholder="Betreff" required /> </div> <div> <textarea name="message" placeholder="Ihre Nachricht" required></textarea> </div> <button type="submit">Senden</button> </form>

📬 Schritt 6: E-Mail Einstellungen prüfen

  • Spam-Ordner von office@fj-marketing.com prüfen
  • E-Mail-Filter deaktivieren
  • Netlify-E-Mails als vertrauenswürdig markieren
  • Alternative E-Mail-Adresse testen

⚡ Schnelle Alternative: Formspree

Falls Netlify Forms weiterhin Probleme macht:

  1. Gehen Sie zu formspree.io
  2. Registrieren Sie sich kostenlos
  3. Erstellen Sie ein Formular für office@fj-marketing.com
  4. Ersetzen Sie in index.html:
<form action="https://formspree.io/f/IHRE_ID" method="POST">

🎯 Debugging Checklist:

  • Formular erscheint in Netlify Dashboard unter "Forms"
  • E-Mail-Benachrichtigung ist konfiguriert
  • Test-Submission erscheint in Form-Liste
  • Spam-Ordner wurde geprüft
  • Alternative E-Mail-Adresse getestet

Wenn gar nichts funktioniert, hier ist ein einfacher mailto-Link:
